# 青养 · 食疗健康生活 APP

一个只在本机浏览器里运行的药食同源 / 药膳 APP。无登录、不联网、无云端，所有数据保存在本机浏览器里，刷新、关闭、重启电脑都不会丢。

## 怎么打开

**方法一：双击 `启动青养.cmd`**

- 会自动启动本地服务并打开浏览器（地址 `http://127.0.0.1:5173/`）。
- 首次需要电脑装有 Node.js（[nodejs.org](https://nodejs.org/) 下载 LTS 版，一路下一步即可）。
- 关闭黑色命令行窗口就等于关闭 APP；需要时重新双击 `启动青养.cmd`。
- 端口被占用时可用：`node scripts/server.mjs --port 5174`。

**方法二：直接双击 `index.html`**

- 不需要任何环境，双击就能用，功能一致（浏览器安全策略下，部分功能如摄像头调用可能受限）。
- 想重新启动时刷新页面即可。

## 四个模块

| 模块 | 能做什么 |
| --- | --- |
| ① 首页 · 物质鉴别 | 40 种药食同源物质；关键词搜索（名称/别名/功效）、按类别筛选、卡片/列表切换；**拍照辅助鉴别**（取照片主色给出候选）、**外形特征逐项选择**（形状/颜色/质地/气味/断面）；物质详情含药典条目、外形特征、成人/青少年分龄参考量、适用状况与相关药膳 |
| ② 身体状况 · 药膳 | 12 种常见身体状况；可用自己的话描述症状来匹配；进入后按**物质**列出适用条目，成人/青少年剂量左右分列对照；对应药膳列出用料、做法、适用人群与注意事项 |
| ③ 药膳社区 | 本机单机社区：发帖（文字 + 照片 + 关联药膳/物质 + 标签）、浏览、按标签/药膳筛选、收藏、点赞、评论；帖子可**导出为分享图片**或文本；可切换本地访客身份模拟多人分享 |
| ④ 数据与设置 | 使用统计与 14 天发帖图；内容管理（帖子、鉴别记录、访客）；**导出/恢复本地备份**（.json）；导出帖子为 Markdown；偏好设置；清空与重置 |

## 数据说明

- 数据存放在浏览器的 IndexedDB（少数环境自动降级到 localStorage）。
- **换电脑、清理浏览器缓存、重装浏览器之前，请先在「数据与设置 → 本地备份」导出 .json 备份。**
- 不同浏览器（Edge / Chrome）的数据互不相通，建议固定用一个浏览器打开。

## 安全口径

- 所有剂量都是**家庭日常参考量**，不是处方，不替代医生诊断与药物治疗。
- 慢性病服药期、孕产妇、婴幼儿、过敏体质请先咨询医师或药师。
- 拍照鉴别只根据照片整体颜色缩小范围，最终请对照外形特征与实物确认，拿不准就不要吃。

## 内容维护

内容数据集中在 `js/data/` 下，改完刷新页面即生效：

- `substances.js`：物质条目（药典信息、性味归经、成人/青少年参考量、外形特征）
- `recipes.js`：药膳（用料、做法、分龄份量、适用状况）
- `conditions.js`：身体状况（自述描述、关键词、调理提示）
